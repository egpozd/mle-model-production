# Релиз модели недвижимости

Учебный проект по выводу модели оценки стоимости недвижимости в продакшен. Сервис принимает характеристики квартиры и возвращает прогноз её стоимости.

Работа продолжает [проект mle-mlflow](https://github.com/egpozd/mle-mlflow), в котором проводились анализ данных, генерация и отбор признаков, а также подбор гиперпараметров. Здесь итоговая модель после подбора гиперпараметров перенесена в отдельный FastAPI-сервис. Совпадение исходного и перенесённого артефактов и их предсказаний проверено. Для работы сервиса не нужны MLflow-сервер и обучающие данные.

В предыдущем проекте итоговая модель обозначалась как V4. Регистрация именно четвёртой версии в MLflow однозначно не подтверждена.

## Что реализовано

- FastAPI-сервис с предсказаниями, валидацией запросов и Swagger.
- Запуск отдельного контейнера через Docker и всех сервисов через Docker Compose.
- Сбор метрик в Prometheus и дашборд из четырёх панелей в Grafana.
- Генератор запросов `generate_load.py` для проверки сервиса под нагрузкой.

Код сервиса находится в `services/ml_service`, модель и необходимые преобразователи в `services/models/v4`. Файл `services/.env` содержит настройки локального запуска и учебные значения. Конфигурация дашборда сохранена в `dashboard.json`, снимок работающего дашборда в `dashboard.jpg`.

## Особенности выполнения проекта

Учебная виртуальная машина Яндекс Практикума была недоступна, поэтому проект выполнен локально на Windows с Docker Desktop. Предыдущий проект по той же причине также выполнялся локально.
