# Релиз модели недвижимости
Сервис оценивает стоимость квартиры с помощью сохранённого Pipeline sklearn и CatBoost. Перенесён итоговый артефакт запуска `52b6764852554b4eb42d49cc5106430a`, названный V4 в README предыдущего проекта. MLflow и обучающие данные для работы не нужны.

В `services/ml_service` находится FastAPI, в `services/models/v4` — модель, её исходная сигнатура и пользовательские преобразователи. SHA256 записан в `services/models/provenance.json`. Пример запроса взят из артефакта модели, без изменения признаков.

Запуск описан в Instructions.md, метрики — в Monitoring.md. Учебный пароль Grafana находится в services/.env; сервисы доступны только с локального компьютера. Не используйте этот пароль для публичного развёртывания.

Обозначение V4 взято из предыдущей работы. Идентичность итогового артефакта подтверждена; номер версии в реестре MLflow по доступным локальным данным однозначно не установлен. Подробности проверок — в REPORT.md.
